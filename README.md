# HPRCA Exam Simulator

Unofficial client-side Digi OMR practice simulator.

## GitHub Pages

Upload `index.html`, `sw.js`, and `manifest.webmanifest` to the repository root and enable GitHub Pages from the repository's Pages settings.

## Features

- Local PDF/TXT/CSV question paper viewer
- No question OCR or question extraction
- PDF zoom, fit-width, fit-page and fullscreen
- Scrollable question paper
- Draggable paper/OMR divider
- 4 or 5 OMR options
- Tap to select/deselect
- 2-second long press on selected option to lock/unlock
- 2-second long press on question number for Mark for Review
- Two-column question palette on wider screens
- Countdown and automatic submission at zero
- Local resume after refresh/close when the same paper is selected
- LocalStorage persistence of answers, review flags, timer and configuration
- Response sheet export as TXT, Markdown, CSV and JSON
- Optional answer-key scoring with configurable negative marking
- PWA/service-worker shell caching after first load

## Important

This is an unofficial practice simulator. It does not claim to reproduce proprietary HPRCA software exactly. Follow the instructions supplied at the actual examination centre.
